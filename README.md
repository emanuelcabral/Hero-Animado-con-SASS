# 🚀 Hero Animado con Sass

Hero section moderno construido con **HTML + Sass (.scss)**, enfocado en el uso de **variables, mixins y bucles `@for`** para crear una animación escalonada (stagger animation) sin JavaScript.

---

## 🎯 Objetivo del proyecto

Este proyecto busca practicar Sass de forma más avanzada, aplicando:

- Sistema de variables centralizado
- Separación de módulos (hero, variables, mixins)
- Animaciones escalonadas con `@for`
- Uso de lógica básica en CSS preprocesado

---

## 🧠 Conceptos de Sass utilizados

- Variables (`$bg`, `$text`, `$primary`, etc.)
- Mixins (`@mixin flex-center`)
- Bucles (`@for`)
- Interpolación (`#{}` en clases dinámicas)
- Organización por archivos parciales

---

## 🎬 Características

- Hero full screen (100vh)
- Fondo con imagen + overlay oscuro
- Texto con animación escalonada (stagger effect)
- Botón con estilo moderno
- Diseño tipo landing page (startup style)

---

## 📁 Estructura del proyecto
- /scss
- _variables.scss → Colores y configuración global
- _mixins.scss → Mixins reutilizables
- _hero.scss → Estilos del hero
- main.scss → Punto principal de compilación
- index.html → Estructura HTML
